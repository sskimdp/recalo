# Recalo

Приложение для заучивания слов по карточкам. Открывается в браузере, ставится на iPhone и Mac как обычное приложение, работает без интернета.

## Что умеет

**Наборы карточек.** Термин и определение. Карточки можно менять местами перетаскиванием, удалять с возможностью вернуть, импортировать списком и выгружать в файл.

**Режим «Карточки».** Карточка переворачивается нажатием, свайп вправо кладёт её в стопку «Знаю», влево — в «Ещё учу». Подсказка открывает ответ по одной букве.

**Режим «Заучивание».** Раунды по семь слов. Новое слово спрашивается выбором из вариантов, знакомое нужно напечатать. Ошибка возвращает слово через пару вопросов. Ответы проверяются строго: регистр и артикли важны, но опечатка в одну букву засчитывается как «почти верно». Если в определении несколько переводов через запятую, подойдёт любой.

**Прогресс.** У каждого слова две независимые шкалы: стопки из режима карточек и ступени заучивания — не изучено, ещё учу, выучено. Обе видны в наборе, сбросить можно любую.

## Запуск

```sh
npm start
```

Откроется по адресу `http://localhost:4173`.

Тесты:

```sh
npm test
```

## Как устроено

Чистый JavaScript без фреймворков и без сборки: файлы открываются браузером как есть.

| Файл | Что внутри |
|---|---|
| `index.html` | разметка, дальше всё рисует JS |
| `app.js` | экраны, жесты, режимы обучения |
| `logic.js` | чистые функции: проверка ответов, слияние данных, поиск, перемешивание |
| `sync.js` | синхронизация через Firebase |
| `styles.css` | оформление, светлая и тёмная темы |
| `sw.js` | офлайн-режим |
| `tests/` | тесты логики |

## Данные

По умолчанию всё хранится в браузере. Приложение никуда ничего не отправляет и не собирает статистику.

Если заполнить `firebase-config.js` настройками своего проекта Firebase, появится вход через Google или по ссылке на почту, а наборы начнут синхронизироваться между устройствами. Локальное хранилище при этом остаётся главным: приложение открывается мгновенно и работает офлайн, изменения уезжают в облако следом.

Отдельно есть резервная копия: все наборы с прогрессом выгружаются в один файл и восстанавливаются из него.

## Установка на устройство

Открыть сайт в Safari и выбрать «На экран Домой» на iPhone или «Добавить в Dock» на Mac. После этого приложение запускается в своём окне, без адресной строки.
